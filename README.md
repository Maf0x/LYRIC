# LYRIC

App web para escribir canciones en iPhone. Un solo archivo (`index.html`), sin cuenta ni servidor. Todo se guarda en tu dispositivo.

## Qué hace

- Editor de letras con guardado automático
- Modo texto libre o por secciones (verso, estribillo, puente…)
- Carpetas, favoritas, estados y etiquetas
- Búsqueda en letras, títulos y notas
- Papelera e historial de versiones
- Exportar a .txt y copias de seguridad en JSON
- Modo claro y oscuro

## Cómo usarla

1. Abre la página en Safari desde tu iPhone. ( https://maf0x.github.io/LYRIC/ )
2. Opcional: Compartir → Añadir a pantalla de inicio.
